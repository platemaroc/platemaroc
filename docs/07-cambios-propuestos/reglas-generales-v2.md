# Reglas generales v2 — propuesta de consolidación

1. Leer el Documento Maestro antes de ejecutar.
2. Si existe conflicto, detenerse y consultar.
3. No inventar datos.
4. Indicar fuente y fecha cuando corresponda.
5. Seguir la documentación oficial vigente de Google para auditorías SEO.
6. Quality Gate = criterio interno por entidad e idioma.
7. No rellenar artificialmente.
8. Claude Code no elimina, archiva ni despublica por iniciativa propia.
9. No guardar secretos en Git ni backups normales.
10. Usar acceso técnico autorizado.
11. Registrar cambios.
12. Mantener independencia editorial.
13. Idiomas: es/en/fr.
14. Sin árabe, RTL ni `hreflang ar`.
15. Publicación bajo aprobación del titular.
16. Las propuestas de modelo de datos requieren aprobación antes de migrar.
