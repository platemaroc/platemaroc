# i18n (es/en/fr)
`config.ts` (prefijos `/es/`, `/en/`, `/fr/`), `negotiate.ts` (sugerencia por `Accept-Language`, sin redirección forzada) y `messages/*.json` (textos de interfaz mínimos).
Las traducciones de CONTENIDO viven en la base de datos (`translations`), no aquí. Sin árabe ni RTL.
Los textos de interfaz de `messages/` son un punto de partida: un hablante nativo debe revisarlos (`ordenes-claude-code/revisar-traducciones/`).
