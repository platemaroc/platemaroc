# Orden: moderar menú

## Objetivo
Revisar menús digitales antes de publicación.

## Comprobar
- relación con el lugar;
- categorías;
- artículos;
- precios (solo MAD);
- alérgenos;
- disponibilidad;
- fotografías;
- traducciones es/en/fr.

No inventar datos.

## Regla
Cada categoría publicada debe tener al menos un artículo publicado.

## Entregable
Informe con elementos aptos, pendientes, rechazables, fuente de datos y aprobación
necesaria.
