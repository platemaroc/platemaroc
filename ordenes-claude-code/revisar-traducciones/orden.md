# Orden: revisar traducciones

## Objetivo
Verificar traducciones es/en/fr.

## Pasos
1. Detectar traducciones en borrador.
2. Comparar datos factuales con la fuente.
3. Revisar títulos, descripciones y metadatos.
4. Revisar que no se introduzcan datos inexistentes.
5. Marcar como revisada solo cuando corresponda.
6. Registrar cambios.

No inventar traducciones de datos que no existan en la fuente.
