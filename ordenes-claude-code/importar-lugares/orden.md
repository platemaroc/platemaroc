# Orden: importar lugares

## Objetivo
Cargar lugares desde una fuente proporcionada por el titular.

## Pasos
1. Validar columnas.
2. Detectar duplicados.
3. Validar ciudad/barrio/coordenadas cuando existan.
4. Generar o validar slug.
5. Cargar como borrador.
6. Informar filas erróneas.
7. Registrar la importación en auditoría.

## Regla
No inventar datos ausentes.
