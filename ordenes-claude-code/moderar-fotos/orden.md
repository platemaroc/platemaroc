# Orden: moderar fotos

## Objetivo
Revisar fotografías y sus derechos antes de publicación.

## Comprobar
- origen;
- autor/licencia cuando corresponda;
- asociación correcta;
- calidad;
- contenido inadecuado;
- datos personales innecesarios;
- alt localizado en es/en/fr mediante `foto_traduccion`.

## Regla
No aprobar una foto con derechos dudosos sin decisión del titular.

## Entregable
Informe de aprobadas, rechazadas y pendientes con motivos.
