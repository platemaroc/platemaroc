# Orden: estado del proyecto

## Objetivo
Crear un informe periódico del estado real.

## Revisar
- lugares;
- contenido;
- traducciones;
- reseñas;
- fotos;
- menús;
- reservas;
- indexación;
- rendimiento;
- seguridad;
- backups;
- pendientes;
- cambios desde el informe anterior.

## Entregable
Informe `AAAA-MM-DD-estado-del-proyecto.md` en `resultados/`.
Debe incluir resumen de 5 líneas, acciones prioritarias, aprobaciones necesarias y
elementos no comprobados.
