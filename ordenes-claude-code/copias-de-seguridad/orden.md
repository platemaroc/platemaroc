# Orden: copias de seguridad

## Objetivo
Comprobar backups e integridad de restauración.

## Política
- BD diaria.
- Fotos/configuración no secreta semanal.
- Retención propuesta: 7/4/3.
- Sin secretos reales.
- Prueba trimestral.

## Pasos
1. Revisar últimos backups.
2. Comprobar cobertura.
3. Comprobar integridad.
4. Probar restauración en entorno seguro cuando corresponda.
5. Informar de fallos.

Nunca copiar valores de secretos a un informe.
